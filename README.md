# Upside Down Synth

Учебный веб-синтезатор в духе «Очень странных дел». Два синтезатора, барабаны, четыре эффекта,
три канала микшера и секвенсор 5×16. Работает без библиотек и сборки: откройте `index.html`.

## Структура

```
upside-down-synth/
├── index.html              — разметка
├── stylesheets/
│   ├── layout.css          — все стили (вид элементов в покое)
│   ├── animation.css       — все анимации и переходы
│   └── images/             — фоны (мир, изнанка) и значки перезагрузки
└── js/
    ├── config.js           — константы: ноты, голоса, профили режимов
    ├── state.js            — текущие значения ползунков и рисунок секвенсора
    ├── audio-engine.js     — каналы, шина, цепочка эффектов
    ├── voices.js           — звук одной ноты синтезатора и барабанов
    ├── sequencer.js        — планировщик нот по часам AudioContext
    ├── interface.js        — клики, ползунки, индикаторы, визуализатор
    ├── modes.js            — переключение «Мир / Изнанка»
    └── main.js             — запуск
```

## Нейминг

| Что | Имена |
|---|---|
| Источники | `synth1`, `synth2`, `drums` |
| Каналы | `ch-s1`, `ch-s2`, `ch-dr` |
| Эффекты | `fx-distortion`, `fx-delay`, `fx-reverb`, `fx-glitch` |
| Секвенсор | `seq-row-s1`, `seq-row-s2`, `seq-row-dr` (внутри три ряда `-kick`, `-snare`, `-hat`) |
| Кнопки | `btn-play`, `btn-mode`, `btn-reset`, `btn-mute` |

Классы — по BEM (`panel__title`). `data-param="ch-s1.volume"` — адрес значения в `state.js`.

## Путь звука

```
synth1 → ch-s1 ┐
synth2 → ch-s2 ┼→ шина → fx-distortion → fx-delay → fx-reverb → fx-glitch → master → выход
drums  → ch-dr ┘
```

## Управление

- ▶ треугольник (или пробел) — играть / остановить
- красный круг — Мир ↔ Изнанка (ниже октавой, темнее, больше баса и эха)
- стрелки — сбросить все выбранные кружки
- основная мелодия играет сама; кружки только добавляют звуки поверх неё (клик: выкл → красный → жёлтый → зелёный)

Цвет кружка: Synth 1 — добавляет ноту арпеджио октавой выше (та же / через одну / через две); Synth 2 — добавляет бас C2 / E2 / G2; барабаны — громко / средне / тихо.
